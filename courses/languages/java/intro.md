## What this course is

Java has been in production for three decades, so most Java work happens inside a codebase someone else
started. That changes what is worth learning. The syntax is small and mostly familiar from any typed
language. The parts that decide whether you are useful on day one are the type system as Java uses it,
the collections and streams you reach for without thinking, and the JVM's behaviour when something is
slow.

This course covers the language, the standard library and the JDK tools. The Spring Boot course covers
the framework, the hosting model and the data layer, and it assumes you can write the Java this course
teaches.

## Who it is for

You know another typed language and want to be productive in Java soon, or you have inherited a Java
service and want to understand what it is doing before you change it.

## What you will build

A command line tool that reads a text file, parses records, transforms them and reports on them. It
grows across the course, and each feature earns its place in the code rather than arriving as an
isolated demo. By the end you have a small program with tests, a clear type model, and measurements that
explain where its time goes.

## Prerequisites

A JDK and a terminal. The first page explains which release to pick and how to install it. Experience
with any typed language is enough to start.

## How the pages are ordered

The first pages cover the toolchain, the build tool and the type system, because everything later
depends on them. From there the pages move through objects, collections and streams, errors and
resources, functional interfaces and concurrency, and finish with testing and the JVM itself. Read them
in order the first time, following the contents list on this page.
