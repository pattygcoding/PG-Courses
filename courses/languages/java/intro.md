## What this course is

Java runs a large share of the software that keeps businesses running, so most Java work happens
inside an existing codebase rather than an empty one. That changes what is worth learning. The
language is small. The runtime, the build tool and the conventions a team uses to keep a large
project readable are where the time goes.

## Who it is for

You know another typed language and want to be productive in Java soon, or you have inherited a Java
service and want to understand what it is doing before you change it.

## What you will build

An HTTP service with a data layer and a test suite, laid out the way a team project is laid out: an
explicit dependency setup, packages that mean something, and code the next person can extend.

## Prerequisites

Comfort with a compiled language and with the command line. Object oriented experience helps, and
the course explains the Java-specific parts as they come up.

## How the pages are ordered

The first pages cover the toolchain and the type system, because everything after them depends on
both. The later pages move through the runtime and into the service you build.
