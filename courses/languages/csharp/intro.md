## What this course is

C# is a typed language with a large, well documented standard library and a toolchain that handles
builds, tests and packaging with little setup. The parts worth learning are the type system, the
async model, and the way .NET organises a project into something a team can share.

## Who it is for

You know another typed language and want to move quickly in C#, or you have a .NET service to
maintain and want to understand the pieces you are looking at.

## What you will build

A console tool first, then the same code behind an HTTP API, with tests that cover the parts that
change often. The second half of the course builds on the first.

## Prerequisites

The .NET SDK and a terminal. Experience with any typed language is enough to start.

## How the pages are ordered

The early pages set up the toolchain and the type system. The middle pages cover async and
collections. The last pages take the console tool you built and expose it over HTTP.
