## What this course is

Python is the language I reach for when the job is to move data, connect two systems, or automate
work I would otherwise repeat by hand. The syntax is short, so you can write something useful on the
first day. That same brevity hides real decisions about types, mutation and errors. This course
walks through those decisions instead of around them.

## Who it is for

You have written some Python, or you are comfortable in another language and want to see how Python
does familiar things. You do not need to know decorators, generators or async before starting.

## What you will build

A command line tool that reads a file, cleans the data, writes a report, and can run again
tomorrow. By the end you have working code, a test for it, and a reason for each choice in it. The
last third of the course covers the tooling around that: virtual environments, packing a project,
formatting, type checks and tests.

## Prerequisites

Python 3 installed and a terminal. Nothing else.

## How the pages are ordered

Read them in order the first time, following the contents list on this page. Each lesson ends with
something you can run or check, and the later lessons assume the earlier code exists. After that,
use the contents list as a reference and jump to whatever you need.
