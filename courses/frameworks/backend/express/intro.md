## What this course is

Express is a small router that sits on Node's HTTP server. The framework takes an afternoon to
learn, and the work is everything around it: where validation belongs, how an error reaches the
client with the right status code, and how to test an endpoint without a browser.

## Who it is for

You know JavaScript or TypeScript and want to build a server you would put in front of users. If you
have written a front end and wondered what happens on the other side of the request, this is that.

## What you will build

An API with routes for reading and writing records, validation on the way in, one place that turns
errors into responses, and a test suite that starts the server and calls it.

## Prerequisites

JavaScript or TypeScript and comfort with the command line. No server experience needed.

## How the pages are ordered

The pages start with a single route and grow the app from there: routing, middleware, validation,
error handling, then tests. Each page leaves you with a server you can call.
