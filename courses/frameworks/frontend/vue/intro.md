## What this course is

Vue gives you single file components, a reactivity system, and a template syntax that stays close to
HTML. The reason to learn it past the tutorial stage is the reactivity model. Once you know what
Vue tracks and when work re-runs, most state and performance bugs stop appearing.

## Who it is for

You know JavaScript or TypeScript and want to build an interface you would ship. If you have used
another component framework, the early pages move faster, and nothing in them assumes you have.

## What you will build

An application with a list, a form, loading and error states, and tests for the behaviour that
matters. It reads from a real endpoint, so the network layer is part of the work.

## Prerequisites

JavaScript or TypeScript, plus enough HTML and CSS to lay out a page. A terminal and Node.js.

## How the pages are ordered

The pages start with the runtime and the template, then the reactivity model, then components and
composition. The application is built across the later pages, one feature at a time.
