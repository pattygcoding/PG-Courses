## What this course is

React is a view library with a small API and a large set of conventions built on top of it. The
mental model is the part that earns the time: a component describes what the screen looks like for a
given state, and React works out how to get there. With that in place, the ecosystem choices make
more sense.

## Who it is for

You know JavaScript or TypeScript and want to build a real interface rather than the counter example
from the documentation. Some experience with another framework helps and is not assumed.

## What you will build

An application with a list, a form, loading and error states, and a test for the behaviour that
matters. It talks to a real endpoint and handles the cases that endpoint actually produces.

## Prerequisites

JavaScript or TypeScript, plus enough HTML and CSS to lay out a page. A terminal and Node.js.

## How the pages are ordered

The pages cover components and state first, then effects and data fetching, then testing. The
application grows across the later pages, so each one leaves you with code that runs.
